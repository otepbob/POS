Clear All Records Deletes every entry in Purchases, Credit Monitoring, Returns & Refunds, Sales Report, the Wallet log and the Audit log, and sets the Cash float (including denomination counts) and GCash float to zero. Products, categories, users and the Admin PIN are kept. Requires the Admin PIN.

☁️ Google Sheets Sync Setup Guide

💡 How it works: The POS app uses Google Apps Script to synchronize with your Google Sheet. When there is no internet, changes save locally to your Excel file and queue automatically. Once internet is back, changes push to Google Sheets instantly!
Follow these 5 easy steps (takes 2 minutes):
  1. Create a new spreadsheet at Google Sheets (e.g. name it "Store POS Database").
  2. In the Google Sheets top menu, click Extensions → Apps Script.
  3. Delete any existing code in the editor, click the Copy Script Code button below, and paste it into the editor. Press Ctrl+S to save.
  4. Click the blue Deploy button (top right) → New deployment.
    • Click the gear icon ⚙️ next to 'Select type' and choose Web app.
    • Description: POS Sync
    • Execute as: Me (your email)
    • Who has access: Anyone (allows POS app to sync)
    • Click Deploy and approve permissions when prompted.
  5. Copy the generated Web App URL (starts with https://script.google.com/macros/s/.../exec) and paste it into POS Settings!
